# 첫 실행본 사용 안내

현재 구현: 수동 OBD 입력 → JSON Schema 확인 → FastAPI → Go Worker → 송신 없는 결과·고정 배정표·실행 기록 조회.

## 실행

이미 준비된 현재 PC에서는 프로젝트 루트에서 다음을 실행합니다.

```powershell
python scripts/dev.py run
```

브라우저: http://127.0.0.1:8080

다른 PC 또는 새 설치에서는 Python 3.14 이상, Go 1.26 이상, Node.js 24.22 이상을 준비하고 다음을 실행합니다. npm이 없으면 준비 명령이 공식 registry의 npm 12.2.2를 프로젝트 내부 .local에 내려받습니다. 시스템 PATH·실행 정책은 변경하지 않습니다.

```powershell
python scripts/dev.py prepare
python scripts/dev.py run
```

소스 수정 후 재빌드: `python scripts/dev.py build`. 확인: `python scripts/dev.py test`. 실행 중인 서버는 종료 후 다시 시작합니다. 로컬 전용이며 외부 서비스로 공개할 인증·운영 구성은 아직 없습니다.

## 확인 순서

1. 차량 3대·풀 Client 2개·차량당 2건의 기본 설정으로 입력·배정 확인을 누릅니다.
2. Worker 생성 확인을 누르면 API가 실제 Go 프로세스에 JSON을 전달합니다. 6건 생성 확인, Client 2개 배정, 실제 연결·발행·PUBACK 0을 확인합니다.
3. 차량별 전체 연결을 선택하면 Client 수가 차량 수에 맞춰집니다. 다시 실행하여 3개의 서로 다른 Client ID를 확인합니다.
4. 위도를 100으로 바꾸면 입력 오류로 거부됩니다.
5. 최근 실행을 선택하면 저장된 결과를 다시 볼 수 있습니다. 다른 조건의 실행은 별도 run_id로 보관합니다.

## 개발용 규격

`contracts/obd-development.json`을 UI 입력 항목과 서버 검증에 공통으로 사용합니다. Microtrip ty=4, Trip ty=3은 공식 표를 기준으로 한 잠정 개발 프로필입니다. 필수값·자료형·위치 범위 등만 검증하며 실제 수신 시스템과의 호환성 확정은 아닙니다. 문서의 단위·자료형 불일치는 필드에 표시했습니다. 실제 개인정보 대신 가상값을 사용하세요.

## 현재 제한

- 실제 MQTT/Paho 연결·TLS 인증·접속 속도 제한·재연결·PUBACK 처리는 아직 미구현입니다. 공통 연결 엔진은 고정 배정·생성 확인 단계까지만 구현했습니다.
- 연결 유지 정책은 실행 설정에 기록하지만 실제 접속/해제 시간 흐름을 재현하지 않습니다.
- 생성 주기는 가상 timestamp 갱신에 적용하며 실제 대기·TPS 제어는 하지 않습니다. 속도·위치·RPM은 입력값을 복제하므로 상태 기반 주행 모사가 아닙니다.
- 차량당 메시지를 복제하고 차량별 tid, 반복별 ts/clt(Trip은 stt/edt)를 갱신합니다. 실차의 운행 전이·Trip 자동 집계는 후속입니다.
- 한 실행 최대 10,000건, 차량 최대 10,000대. 결과는 배정 최대 100대·샘플 최대 10건만 보관합니다. 데이터 파이프라인 검증용 전량 저장이 아닙니다.
- 실행 설정은 생성 후 변경할 수 없습니다(PATCH 409). 현재 작업은 동기적으로 짧게 완료되며 장시간 실행·일시중지·분산 복구는 아직 없습니다.
- API가 .local/runs.sqlite3에 실행별 요청과 결과를 저장합니다. 로컬 SQLite는 개발용이며 AWS 상태 저장소는 미확정입니다.
- Worker는 stdin/stdout JSON으로 API와 통신합니다. 이후 MQTT 전송 기능을 추가해도 배정 계산과 입력 계약을 재사용할 수 있습니다.

## 확인 결과

- Go 테스트: 공유 배정·일대일 고유성, 생성 수량, 시각 갱신, 입력 상한, 실제 전송 경로 차단.
- API 통합 테스트 10개 통과: 스키마 예제, Worker 실행, 실행 기록·설정 고정, 두 배정 방식, Trip, 잘못된 입력 거부.
- TypeScript 검사·Vite 빌드 통과.
- 브라우저: 미리보기, 풀·전체 연결 각각 6건 생성 확인, 위도 오류 한국어 표시, 서버 재시작 후 실행 기록 조회 확인.
- 테스트 도구에서 httpx 연동 사용 중단 예고 경고 1건이 있으나 테스트는 통과했습니다. 현재 버전을 lock 파일에 고정했습니다.

실제 AWS 자원 생성·송신·지출은 없습니다. 다음 기능은 실제 MQTT 전송 어댑터와 연결 수명 관리이며, AWS 시험 전에 수신 규격·토픽·인증 정책을 확인해야 합니다.
