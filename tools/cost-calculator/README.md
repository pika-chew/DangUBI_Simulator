# 서울 IoT 비용 계산기

`cost-calculator.html`을 브라우저에서 직접 열면 설치나 서버 없이 사용할 수 있습니다. 인터넷 요청은 발생하지 않습니다.

`seoul-cost-config.json`은 기본 입력값과 서울 단가입니다. 화면의 **JSON 불러오기**로 적용하고 **설정 JSON 저장**으로 변경값을 내보냅니다. HTML 내부에 같은 기본 설정이 포함되어 있어 파일을 직접 열어도 작동합니다. 외부 JSON을 편집해도 화면에 자동 반영되지는 않으므로 불러오기를 사용하세요. 계산 결과 JSON은 설정·계산 결과·비교 보관함을 포함합니다.

HTTP로 열려면 프로젝트 루트 터미널에서 다음을 실행합니다.

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory tools/cost-calculator
```

이후 http://127.0.0.1:8765/cost-calculator.html 을 엽니다. `requests.http`에서 화면과 JSON에 GET 요청을 보낼 수도 있습니다. 계산은 브라우저에서 수행하며 별도 POST API는 없습니다.

## 조정 항목

- 차량 수, 0 초과~30일 수집 기간, 하루/전체 기준 운행시간
- 생성 주기(초), payload 바이트, 종료 Trip 포함 여부, 하루 운행 횟수
- 풀/차량별 전체 연결, 상시/운행 연동/직접 지정 유지시간
- 풀 가동시간, 피크 동시 운행 비율, 연결당 목표 속도
- 추가 발행 비율, 구독자 수, Rule·Action, 기존 월 과금 메시지 단위
- 선택 Fargate 비용, 공용 IPv4, 기타 예산, 예비비, 가정 환율·세율
- 수정 가능한 단가, 조건 비교 10개, 설정 및 결과 JSON 내보내기

## 계산과 한계

연결 비교표는 상시 유지/운행 연동 각각에 대해 풀과 차량별 연결을 나란히 비교합니다. 모든 차량이 같은 시간에 운행하면 풀 운행 연동 가동시간도 차량당 운행시간과 같습니다. 차량들이 수집 기간 전체에 나누어 운행하면 풀은 기간 전체에 걸쳐 필요할 수 있습니다. 두 배치를 버튼으로 선택하거나 풀 가동시간을 직접 입력할 수 있습니다. `poolWindowBasis`는 `custom`(직접 지정), `synchronized`(동시 운행), `distributed`(기간 전체 분산) 값을 사용합니다. 기존 JSON에는 이 값이 없으면 `custom`을 적용합니다.

평균 운행량으로 메시지 수를 계산하므로 분수 건수가 나타날 수 있습니다. 실제 개별 운행별 주기 절삭·시작 즉시 발행을 재현하지 않습니다. 연결시간은 세션별 1분 올림이나 재접속을 재현하지 않은 근사값입니다. 풀 가동시간은 차량들의 운행이 겹치는 정도에 따라 직접 입력해야 합니다. 피크 TPS는 Microtrip 기준이며 종료 Trip·순간 동시 발행은 별도 분산해야 합니다.

모든 메시지를 5,120바이트 단위로 올림하고 월 첫 10억/다음 40억/50억 초과 단가를 적용합니다. 다른 월 사용량이 있으면 기존 과금 단위를 입력합니다. 수집 기간은 같은 청구월 안이라고 가정합니다. Rule은 최소 1 action 과금 기준을 적용합니다.

USD/원 환산은 사용자 환율 가정이며 실시간 시세가 아닙니다. 세금·예비비는 전체 계획 예산에만 적용하고 IoT Core 원가에는 포함하지 않습니다. 무료 혜택은 적용하지 않습니다. 메시지 영구 저장·NAT·UI/API·로그 등은 자동 산정하지 않으며 기타 예산에 직접 반영합니다. 자원 가격 계산은 실측 처리 용량 또는 AWS 자원 조합의 유효성 검사가 아닙니다.

단가 근거는 `../../docs/SOURCES.md`, 상세 원본은 `../../docs/awsiot-seoul-price-source.json` 및 `../../docs/fargate-seoul-price-source.json`에 있습니다. 계산기 검증은 `node tools/cost-calculator/verify.cjs`로 실행합니다.
